# DR.MOEEN AESTHETICS — אתר המרפאה (גרסת דמו)

אתר סטטי, רב-עמודי, בעברית (RTL) למרפאת **DMC של ד"ר מטאנס מועין**.
נבנה לפי חבילת המסירה `DR-MOEEN-Claude-Handoff` ולפי העיצוב המאושר
(`reference/approved-design.png`) — שחור וזהב, לוגו מקורי, סרטון המרפאה האמיתי.

> **גרסת דמו לבדיקה בלבד.** האתר אינו מחליף את האתר הפעיל, אינו מחובר ל-DNS של
> `drmatanis.com`, והטופס אינו שולח פניות למרפאה עד שיוגדר יעד שרת (ראו למטה).

כתובת הדמו (GitHub Pages): **https://orgme24.github.io/drmoeen/**

---

## מה כולל האתר

- **38 נתיבים ציבוריים** — כל הנתיבים שב-`content/route-map.csv`, כולל שמירת
  ה-slugs המקוריים בעברית ובאנגלית (ל-SEO).
- **עמוד בית** התואם את תמונת הייחוס: Header (לוגו מימין, תפריט, כפתור זהב
  לתיאום משמאל), Hero עם נגן וידאו אמיתי + כותרת, קו גלי זהוב, "קריות • מעיליא",
  שלושה כרטיסי קטגוריות, ביוגרפיית רופא, 11 חוות דעת, קליניקות וטופס.
- **לוגו מקורי** (`assets/a04bd68c52c9f78f.webp`) ו**סרטון מרפאה מקורי**
  (`assets/2f17abda5272a3ba.mp4`, משך אמיתי ~57.98 שניות) — הנגן מציג את המשך
  האמיתי, לא את 2:28 שבהדמיה.
- **תוכן מקור מלא** לכל עמוד טיפול/מאמר (כותרות, פסקאות, שאלות ותשובות),
  פירורי לחם, תמונות מקור, וקישורי טיפולים קשורים.
- **טופס יצירת קשר** עם כל השדות מה-site-config, ולידציה, מניעת שליחה כפולה,
  והודעות הצלחה/כשל — ללא מצג שווא (ראו "חיבורים חסרים").
- **נגישות ו-RTL**: `lang=he`, `dir=rtl`, H1 אחד לעמוד, labels, פוקוס גלוי,
  ניווט מקלדת, `prefers-reduced-motion`, תפריט מובייל מתקפל.
- **SEO**: שמירת `title` ו-`meta description` המקוריים, `canonical` לדומיין
  הייצור, `sitemap.xml`, `robots.txt` (חוסם אינדוקס בגרסת הדמו), `404.html`,
  ועמוד `thank-you` עם `noindex`.

## מבנה

```
index.html                 עמוד הבית
<slug>/index.html          עמוד לכל נתיב (שם התיקייה = ה-slug המקורי)
assets/                    מדיה מקורית + site.css + site.js
sitemap.xml robots.txt 404.html .nojekyll
```

כל הקישורים הפנימיים **יחסיים** (`../`), כך שהאתר עובד זהה ב-GitHub Pages,
בדומיין מותאם, או מקומית — ללא תלות בנתיב הבסיס.

## הרצה מקומית

```powershell
cd drmoeen-site
python -m http.server 8787
```
ואז פותחים `http://127.0.0.1:8787/`.

## חיבורים ונכסים חסרים (לא זמינים בחבילה הציבורית)

יש להשלים לפני עלייה לאוויר:

1. **יעד שליחת הטופס** — אין בחבילה כתובת מייל, CRM, מזהי טופס או הרשאות שליחה.
   כרגע הטופס **אינו מתחזה לפעיל**: אם לא הוגדר endpoint הוא מציג הודעה
   המפנה לטלפון/וואטסאפ. להגדרת יעד אמיתי (למשל Formspree / Getform / שרת משלכם)
   יש להוסיף לפני הטופס:
   ```html
   <script>window.DRMOEEN_FORM_ENDPOINT = "https://formspree.io/f/XXXX";</script>
   ```
   או `data-endpoint="..."` על `<form id="contact-form">`. הטופס שולח `multipart/form-data`.
2. **קישור וואטסאפ** — נשמר הקישור הציבורי שנמצא (`8ight.design/go?id=dmc`),
   התלוי בספק חיצוני. להחליפו ל-`wa.me` ישיר רק לאחר אימות היעד.
3. **דוא״ל ושעות פתיחה** — לא פורסמו באתר המקור; לא הומצאו כאן.
4. **מערכת ביקורות** — בעמוד חוות הדעת הציבורי לא הוצגה רשימת ביקורות; מוצגות
   רק 11 חוות הדעת שנמצאו בעמוד הבית. חיבור למערכת ביקורות חיצונית = פער להשלמה.
5. **תמונות הקטגוריות שבהדמיה** — אינן קבצי מקור עצמאיים. בכרטיסי הקטגוריות
   נעשה שימוש בתמונות הקטגוריה **המקוריות** מהמיפוי (`original_category_images`),
   שעשויות להיראות שונה מהתמונות שבתמונת הקונספט.
6. **DNS / דומיין** — הדמו ב-GitHub Pages בלבד; אין שינוי ל-`drmatanis.com`.

## הערות שימור תוכן

- רכיבי Header ו-Footer החוזרים הופרדו לרכיבים משותפים; תוכן הגוף של כל עמוד נשמר.
- קרדיט ספק האתר הישן ("Digital Studio") לא הוצג כקרדיט לבונה החדש; נשמרו
  ההבהרות המשפטיות והקרדיט לבעלי המרפאה בלבד.
- לא נוספו טיפולים, מחירים, הסמכות, שעות או הבטחות תוצאה שלא הופיעו במקור.
