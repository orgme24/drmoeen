# DR.MOEEN AESTHETICS — אתר המרפאה (גרסת דמו)

אתר סטטי, רב-עמודי, בעברית (RTL) למרפאת **DMC של ד"ר מטאנס מועין**.
נבנה לפי חבילת המסירה `DR-MOEEN-Claude-Handoff` ולפי **האפיון העיצובי המעודכן**
(ההדמיה הירוקה): רקע ירוק עמוק (`#102C29`), שנהב (`#ECE7DD`) ונחושת מעודנת
(`#B46C50`) — אופי קולנועי, לוגו מקורי וסרטון המרפאה האמיתי.

> **הערה על הרפרנס:** תמונת ההדמיה הירוקה עצמה לא צורפה לחבילה (בחבילה קיים רק
> `reference/approved-design.png` בשחור-זהב). העיצוב מומש מתוך האפיון הכתוב
> המפורט; מומלץ להשוות לתמונת ההדמיה הירוקה כשתתקבל כדי לכייל פונט/מרווחים.

> **גרסת דמו לבדיקה בלבד.** אינה מחליפה את האתר הפעיל, אינה מחוברת ל-DNS של
> `drmatanis.com`, והטופס אינו שולח פניות עד שיוגדר יעד שרת (ראו למטה).

כתובת הדמו (GitHub Pages): **https://orgme24.github.io/drmoeen/**

## עמוד הבית לפי האפיון

- **Header ירוק עמוק** — לוגו מקורי מימין, ניווט (אודות · טיפולי פנים · טיפולי גוף
  · רפואת שיניים · צור קשר), וכפתור מסגרת עדין "לתיאום פגישת ייעוץ" משמאל.
- **אזור פתיחה קולנועי** — סרטון המרפאה המקורי כמרכז החזותי, עם שכבות ירוק כהה
  לקריאות. מעליו כותרות מדורגות: **"דיוק שרואים."** (ימין־עליון) ו**"יחס שמרגישים."**
  (נמוך יותר לשמאל), וטקסט משני "רפואת שיניים ואסתטיקה בגישה אישית".
  כפתור **"הסרט של המרפאה"** מפעיל הפעלה/השהיה, השתקה, פס התקדמות ומסך מלא.
  המשך האמיתי של הסרטון נקרא מהקובץ (~0:57) ולא 2:28.
- **פס תחומי טיפול בשנהב** — `01 / טיפולי פנים`, `02 / טיפולי גוף`,
  `03 / רפואת שיניים`, עם קווים דקים, מספרי נחושת וחצים עדינים; כל פריט מקשר לעמוד.
- **"נעים להכיר."** — אזור בהיר עם תמונת הרופא, כותרת־על "האדם מאחורי הדיוק",
  תוכן האודות המקורי וקישור.
- **תחומי הטיפול** — מקטע עריכתי מדורג (מספר, תמונה, טקסט) — לא רצף כרטיסים זהים.
- **חוות דעת** (11 אמיתיות), **קליניקות** וטופס תיאום — שילוב אזורים בהירים וכהים.

ללא זהב זוהר, הצללות כבדות, ואפקטים דקורטיביים. ללא ריווח מלאכותי בין אותיות
בעברית. כותרות בגופן סריפי אלגנטי (Frank Ruhl Libre) — להתאמה סופית מול ההדמיה.

## כלל האתר

העיצוב החדש חל על **כל 38 הנתיבים** שב-`route-map.csv` (שמירת ה-slugs בעברית
ובאנגלית ל-SEO), עם אותה שפה חזותית, רוחב קריאה נוח וכפתור תיאום ברור. כל התוכן
הציבורי מהחבילה הועבר: טיפולים, אודות, תמונות, המלצות, קשר, קישורים ומסמכים
משפטיים — ללא השמטה וללא המצאת נתונים.

## מבנה

```
index.html                 עמוד הבית
<slug>/index.html          עמוד לכל נתיב (שם התיקייה = ה-slug המקורי)
assets/                    מדיה מקורית + site.css + site.js
build.py                   מחולל האתר (קורא את חבילת המסירה)
sitemap.xml robots.txt 404.html .nojekyll COVERAGE.md
```

כל הקישורים הפנימיים **יחסיים** (`../`) — האתר עובד זהה ב-GitHub Pages, בדומיין
מותאם, או מקומית.

## הרצה / בנייה

```powershell
cd drmoeen-site
python -m http.server 8787   # הרצה מקומית → http://127.0.0.1:8787/
python build.py              # בנייה מחדש מהחבילה
```

## חיבורים ונכסים חסרים (להשלמה לפני עלייה לאוויר)

1. **יעד שליחת הטופס** — אין בחבילה מייל/CRM/הרשאות. הטופס אינו מתחזה לפעיל: ללא
   endpoint הוא מפנה לטלפון/וואטסאפ. להגדרה:
   ```html
   <script>window.DRMOEEN_FORM_ENDPOINT = "https://formspree.io/f/XXXX";</script>
   ```
   או `data-endpoint="..."` על `<form id="contact-form">`.
2. **קישור וואטסאפ** — נשמר הקישור הציבורי (`8ight.design/go?id=dmc`); להחליף
   ל-`wa.me` ישיר רק לאחר אימות היעד.
3. **דוא״ל ושעות פתיחה** — לא פורסמו במקור; לא הומצאו.
4. **מערכת ביקורות חיצונית** — מוצגות רק 11 חוות הדעת שנמצאו בעמוד הבית.
5. **תמונת ההדמיה הירוקה** — לא בחבילה; העיצוב מתוך האפיון הכתוב (ראו למעלה).
6. **DNS / דומיין** — דמו ב-GitHub Pages בלבד; ללא שינוי ל-`drmatanis.com`.
